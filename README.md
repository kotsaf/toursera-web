# 🌍 toursera

**многостраничный веб-сайт туристического агентства на django**

проект для знакомства с туристическим агентством, просмотра предложений туров, отзывов клиентов и контактной информации. разделы сайта объединены общим оформлением и навигацией

---

## ✨ возможности

- **главная страница** - представление агентства и знакомство с сайтом
- **о компании** - отдельный раздел с информацией об агентстве
- **туры** - страница туристических предложений
- **отзывы клиентов** - отображение отзывов, загружаемых из базы данных
- **контакты** - отдельная страница с контактной информацией
- **навигация** - переходы между основными разделами сайта

## 🛠 технологии

| технология | применение |
|---|---|
| python | серверная логика |
| django | обработка запросов, маршрутизация и формирование страниц |
| django orm | описание моделей и взаимодействие с базой данных |
| sqlite | хранение данных |
| html | структура страниц и шаблоны django |
| scss / css | оформление интерфейса |
| javascript | интерактивные элементы на страницах |

## 🗂 работа с данными

в проекте предусмотрены две основные модели:

**туры**
- название
- описание
- стоимость

**отзывы**
- имя автора
- заголовок
- текст отзыва
- дата публикации с автоматическим заполнением при создании записи

страница отзывов получает записи через django orm и отображает их с помощью серверного шаблона

## ⚙️ архитектура

приложение организовано по структуре django с разделением ответственности:

- **модели** описывают данные туров и отзывов
- **представления** обрабатывают запросы и передают данные на страницы
- **маршруты** связывают адреса сайта с представлениями
- **шаблоны** формируют html-страницы
- **статические ресурсы** содержат стили, скрипты и изображения

проект объединяет клиентскую часть на html, scss и javascript с серверной частью на python и django
