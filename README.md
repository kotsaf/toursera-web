##toursera
toursera - многостраничный веб-сайт туристического агентства на django. в проекте реализованы главная страница, раздел о компании, страницы туров, отзывов и контактов. страницы объединены общим оформлением и навигацией, серверная маршрутизация связывает каждый раздел с соответствующим представлением и html-шаблоном
серверная часть написана на python с использованием django. для хранения данных используется sqlite, взаимодействие с базой организовано через django orm. предусмотрены модели туров с названием, описанием и ценой, а также отзывов с именем автора, заголовком, текстом и датой публикации. на странице отзывов данные извлекаются из базы и передаются в шаблон для отображения
клиентская часть построена на html, scss, css и javascript. html-шаблоны формируют структуру страниц, scss и css отвечают за оформление, javascript используется для интерактивных элементов интерфейса. статические ресурсы и шаблоны выделены в отдельные каталоги django-приложения
основные возможности проекта:
- навигация между разделами туристического агентства
- отдельная страница для представления туров
- хранение названий, описаний и стоимости туров в базе данных
- хранение и отображение отзывов клиентов
- автоматическое заполнение даты отзыва при создании записи
- страницы с информацией о компании и контактами
- разделение серверного кода на модели, представления, маршруты и шаблоны
технологии: python, django, django orm, sqlite, html, scss, css, javascript
